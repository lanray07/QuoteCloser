# QuoteCloser

QuoteCloser is a SwiftUI iOS app for creating service-business quotes, AI-assisted proposals, follow-ups, objection replies, upsells, pipeline tracking, analytics, PDF exports, and StoreKit 2 subscription scaffolding.

Mock AI is enabled by default. Replace the placeholder endpoint in `RemoteAIService` with your own secure backend before using live AI. Do not ship API keys inside the app.

Minimum target: iOS 17.0.
